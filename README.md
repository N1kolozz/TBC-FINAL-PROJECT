# SheltMe

SheltMe is a web platform designed to connect individuals who can offer shelter ("shelter givers") with those who are in immediate need of affordable or free shelter ("shelter seekers").

## Features

*   **Home Page:** Provides an overview of the platform and its purpose.
*   **About Us:** Information about the SheltMe project.
*   **Services:** Details about the services offered to both shelter givers and seekers.
*   **News:** Latest updates and relevant news.
*   **Contact:** Ways to get in touch with the SheltMe team.
*   **Account Registration:** Users can register as either a "shelter giver" or "shelter seeker."
*   **Multilingual Support:** (Based on the language selector in the header, though actual functionality needs verification)

*   **Explore the navigation bar** to visit different sections of the website like Home, About us, Services, News, and Contact.
